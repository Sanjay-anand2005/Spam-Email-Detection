# Spam Detection Using Machine Learning

## Project Description
A Machine Learning project that classifies emails as Spam or Ham using TF-IDF feature extraction and Logistic Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression

## Project Workflow
1. Data Collection
2. Data Cleaning and Preprocessing
3. Label Encoding
4. Train-Test Split (80:20)
5. Text Feature Extraction using TF-IDF
6. Model Training using Logistic Regression
7. Model Evaluation using Accuracy Score
8. Spam/Ham Email Prediction

## Dataset
The project uses `mail_data.csv`, containing email messages classified as Spam or Ham.

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Open `Spam Detection.ipynb` using Jupyter Notebook.
4. Run all cells to train and evaluate the model.

## Model
- Algorithm: Logistic Regression
- Feature Extraction: TF-IDF
- Training Data: 80%
- Testing Data: 20%

## Output
The model predicts whether an input email is Spam or Ham and displays the corresponding prediction probability.
